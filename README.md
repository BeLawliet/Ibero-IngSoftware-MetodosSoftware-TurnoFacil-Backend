# TurnoFácil

### Gestión sencilla de citas y servicios

</div>

## ¿Qué es TurnoFácil?

TurnoFácil es una aplicación web pensada para ayudar a un negocio a organizar sus citas y consultar su agenda de manera rápida y clara.

Desde un solo lugar permite llevar el control de clientes, empleados y servicios, facilitando las tareas diarias del establecimiento.

Este repositorio contiene el **backend** del proyecto, es decir, la parte encargada de procesar las solicitudes, aplicar las reglas del sistema y almacenar la información.

## Funciones principales

- Permitir el inicio de sesión en el sistema.
- Registrar y administrar citas.
- Gestionar la información de los clientes.
- Gestionar los empleados y su disponibilidad.
- Administrar los servicios ofrecidos por el negocio.
- Guardar y consultar la información del sistema.

## Tecnologías utilizadas

El proyecto fue desarrollado con **Java**, **Spring Boot** y **PostgreSQL**.

## Estado del proyecto

TurnoFácil se encuentra en desarrollo académico. Este backend proporciona los servicios necesarios para conectar la interfaz del usuario con la base de datos y gestionar la información del negocio.
